# 教师教育理论刷题离线版

这是从原项目 Excel 题库生成的纯静态 PWA 包，不需要 Python 后端。

## 内容

| 题库 | 题数 |
|---|---:|
| 大学心理学2026 | 516 |
| 教师伦理学2026 | 650 |
| 高等教育学2026 | 449 |
| 高等教育法规与政策2026 | 559 |

合计：2174 题。

## 手机使用

推荐把本目录发布到 HTTPS 静态站点后，用手机浏览器打开并添加到主屏幕。首次打开完成后，题库会被 Service Worker 缓存，之后可以离线刷题。

直接双击 `index.html` 适合查看页面，但部分手机浏览器会限制本地 JSON 读取和离线缓存；因此真正的手机离线体验建议通过 HTTPS 首次安装。

## 数据说明

题库数据来自原项目中的四个 `2026.xlsx` 文件。做题进度、错题、备份和 AI 解析配置仍保存在当前浏览器的 localStorage 中。
